# Вики · wiki.nmchv.ru

Сайт с четырьмя разделами: **Конспекты**, **Термины**, **Презентации** и **Практические работы**. Работает на GitHub Pages, без сборки.

## Запуск
1. Создайте репозиторий на GitHub (например `wiki`) и загрузите в него **содержимое этой папки** (`index.html` должен лежать в корне).
2. Settings → Pages → Source: *Deploy from a branch* → ветка `main`, папка `/ (root)`.
3. Settings → Pages → Custom domain: `wiki.nmchv.ru` (файл `CNAME` уже есть), включите *Enforce HTTPS*.
4. В DNS для `wiki.nmchv.ru` создайте CNAME-запись на `<ваш-логин>.github.io`.

## Админка
Кнопка «Админ» в шапке, пароль — `geo2026`. При первом входе откройте вкладку «Настройки» и вставьте GitHub-токен
(fine-grained, доступ только к этому репозиторию, Contents: Read and write). Дальше можно добавлять и менять
конспекты, презентации, практические работы, термины и темы поурочного планирования прямо с сайта — изменения коммитятся в репозиторий, сайт обновляется за 1–2 минуты. Для презентаций и практических работ указывайте номер по федеральному перечню: его можно искать в каталогах, а при загрузке выбрать тематический значок. Вкладка «Планирование» принимает список строк из Excel или Google Таблиц (урок, федеральный номер, тема); в таблице можно привязать презентацию и практическую работу к каждой теме и сохранить весь список сразу. На главной странице планирование открывается по нажатию на сворачиваемый блок «Поурочное планирование». PDF-файлы можно просматривать прямо на сайте или скачивать. Дату указывать не нужно: материалы хранятся без даты.

## Структура
- `data/*.json` — списки конспектов, презентаций, практических работ, терминов и поурочного планирования (можно править руками)
- `files/notes/<класс>/` — PDF конспектов; `files/slides/<класс>/` — PPTX и PDF презентаций; `files/works/<класс>/` — PDF практических работ
- `assets/` — стили и скрипты; цвета — в начале `assets/style.css`
